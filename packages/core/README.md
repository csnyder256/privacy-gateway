# `@privacy-gateway/core`

Portable TypeScript/WebCrypto policy, detection, transformation, and restoration core for
[Privacy Gateway](https://github.com/csnyder256/privacy-gateway). It runs in modern browsers
and Node.js 20+ without sending source text to the gateway.

See the [project quick start](https://github.com/csnyder256/privacy-gateway#quick-start),
[threat model](https://github.com/csnyder256/privacy-gateway/blob/main/THREAT-MODEL.md), and
[limitations](https://github.com/csnyder256/privacy-gateway/blob/main/docs/limitations.md)
before production use.
