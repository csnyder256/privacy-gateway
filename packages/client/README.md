# `@privacy-gateway/client`

Browser and Node.js 20+ HTTP client for
[Privacy Gateway](https://github.com/csnyder256/privacy-gateway). It includes Promise-based
request helpers, structured blocked-state errors, and redirect refusal.

See the [project quick start](https://github.com/csnyder256/privacy-gateway#quick-start),
[agent setup guide](https://github.com/csnyder256/privacy-gateway/blob/main/AGENT-GUIDE.md),
and [limitations](https://github.com/csnyder256/privacy-gateway/blob/main/docs/limitations.md).
