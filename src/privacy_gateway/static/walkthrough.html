What this walkthrough proves

It proves the decisions and cryptographic restoration for this specific input and configured detectors. Disabled and keep rules are not scanned. Unrecognized sensitive data can remain in output. A protected state is not a guarantee that all PII was found.

Client-held means the page retains the recovery key without writing it to storage. The transform and restoration API see that key during the operation. For a stricter client trust boundary, use the local TypeScript core rather than sending originals to a remote gateway.

After each transform this page deletes its temporary gateway session. Audit events may remain under server retention settings. Capsules are self-contained: deleting a server session does not revoke a copied capsule. Clear or close the page to discard the in-memory capsule and key.
