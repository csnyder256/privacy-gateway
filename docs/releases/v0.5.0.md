# Interactive privacy lab and reproducible benchmarks — v0.5.0

Use the packaged /walkthrough page to transform invented samples with the running engine, vary a policy, inspect an opt-in decision trace and restore approved values from an encrypted capsule. The page deletes its temporary gateway session after each transform and holds its recovery key only in tab memory. The gateway sees that key during API calls; client-held does not mean the gateway cannot access it.

Policy traces record UTF-8 spans, detector identity, confidence, rule priority, scope and outcomes without original matched values. Required detectors fail closed. The CLI and local demo benchmark score a labeled invented corpus by exact entity and byte spans, report misses and blocked cases, and export JSON/CSV/HTML with corpus, policy and code fingerprints. This small corpus does not estimate production detection coverage. Capsule copies are not revoked by server session deletion.

## Install and upgrade

Use the versioned [deployment instructions](https://github.com/csnyder256/privacy-gateway/blob/v0.5.0/DEPLOYMENT.md) and verify the release checksums before upgrading. Preserve existing user data and policy configuration.
